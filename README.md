# South African Labour Market Analysis

## Overview

This project provides a statistical analysis of South Africa's labour market, with a particular focus on unemployment.

The aim is to investigate how unemployment has changed over time, identify differences across provinces and demographic groups, examine statistical relationships within the labour market, and forecast future unemployment trends.

The project will use publicly available South African labour market data and Python for data cleaning, statistical analysis, visualisation, modelling, and forecasting.

## Research Questions

This project aims to answer the following questions:

1. How has South Africa's unemployment rate changed over time?
2. Which provinces experience the highest and lowest unemployment rates?
3. How does unemployment differ across age groups?
4. How does unemployment differ between demographic groups?
5. Are differences in unemployment across provinces and demographic groups statistically significant?
6. What factors are associated with unemployment in South Africa?
7. Are there identifiable long-term trends or seasonal patterns in unemployment?
8. Which forecasting model performs best for South African unemployment data?
9. What does the selected model suggest about unemployment over the next several quarters?

## Planned Analysis

The project will include:

- Data collection and cleaning
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Provincial unemployment analysis
- Demographic and youth unemployment analysis
- Statistical hypothesis testing
- Regression analysis
- Time-series analysis
- ARIMA and ETS forecasting
- Forecast model comparison
- Interpretation of results
